# Custom WordPress Theme | Oftalmed.by

Кастомная тема для сети оптик **[Oftalmed.by](https://oftalmed.by/)**. Проект разработан в составе команды **ITG-Soft** в рамках полного редизайна и оптимизации сайта.

---

## 🚀 Ключевые особенности проекта

- **Архитектура на ACF Blocks (Gutenberg):** Полностью компонентный подход без перегруженных фреймворков и тяжёлых билдеров (Elementor/WPBakery). Высокая скорость загрузки и удобное управление контентом из админ-панели.
- **Оптимизация производительности:** Минимальное количество внешних зависимостей, чистый PHP-код, асинхронная загрузка скриптов и стилей.
---

## 🛠 Технологический стек

- **CMS:** WordPress
- **Core:** PHP 8.x, Advanced Custom Fields Pro (ACF Blocks)
- **Frontend:** JavaScript, SCSS/CSS3, HTML5
---
